## Установка
1. Клонирование репозитория
```
git clone https://github.com/EvgeniyVertianov/course_paper_1
```
2. Установка зависимостей
```
poetry install
```
3. Для работы с внешним API необходимо создать файл `.env` в корневой директории проекта 
и добавить в него переменную окружения (для информации есть шаблон `.env_template`):
```
API_TOKEN=your_api_token_here
```

## Описание модуля `views`

Основные функции для генерации JSON-ответов находятся в отдельном модуле `views`.
Данные для анализа и вывода на веб-страницах — это данные с начала месяца, на который выпадает входящая дата, 
по входящую дату.

## Описание модуля `utils`
Модуль `utils` предоставляет функции:  
* `greet` приветствие в формате "???", где ???— «Доброе утро» / «Добрый день» / «Добрый вечер» / «Доброй ночи» 
в зависимости от текущего времени.  
* `get_date` принимает на вход дату в формате *2020-01-11 16:30:00* и формирует период с начала месяца до 
указанной даты.  
* `read_xlsx` считывает данные из Excel файла и преобразовывает их в DataFrame.  
* `get_period` принимает данные из Excel и фильтрует их по указанному периоду, возвращая таблицу.  
* `get_data_cards` принимает DataFrame и возвращает последние 4 цифры карты с общей суммой расходов 
и кэшбэк по этим картам.  
* `get_top_five` принимает DataFrame и возвращает top транзакций по сумме платежа.  
* `get_currency_rate` принимает путь к файлу Json и возвращает курс валют.  
* `get_stock_prices` принимает путь к файлу Json и возвращает стоимость акций.  
* `get_transactions` принимает DataFrame и возвращает список транзакций.  
* `get_phone_numbers` принимает список транзакций, фильтрует его и возвращает список транзакций в описании
которых есть телефонные номера.

Все функции модуля поддерживают ведение логов.

## Описание модуля `reports` 

* декоратор `decorator`  
Декоратор для функций-отчетов записывает в файл результат, который возвращает функция, формирующая отчет.  
Декоратор без параметра — записывает данные отчета в файл с названием по умолчанию.  
Декоратор с параметром — принимает имя файла в качестве параметра.  

* функция `spending_by_category` формирует траты по категории.  

Функция принимает на вход:

1) DataFrame с транзакциями;
2) название категории;
3) опциональную дату.
Если дата не передана, то берется текущая дата.

Функция возвращает траты по заданной категории за последние три месяца (от переданной даты).

## Описание модуля `services`
Поиск по телефонным номерам реализован в модуле `services`.
* Функция `main_services` принимает DataFrame и возвращает JSON со всеми транзакциями, содержащими в описании 
мобильные номера.  
Пример JSON-ответ:
